# 项目日志 2026-11-16

## 项目概述

**军队文职刷题网页**：公共科目 + 数学1 在线刷题平台。
- 功能范围（用户已确认）：完整版——章节练习、随机练习、即时判分+解析、错题本、学习统计、模拟考试（计时/答题卡/交卷报告）
- 视觉：极简白灰；布局：手机优先响应式
- 数学1 公式：按题切图（题干图片 + 选项按钮判分），公共科目纯文本入库
- 部署：GitHub Pages（Gitee→GitHub 镜像），**仓库私有**（题库含机构资料，避免公开传播）

## 技术栈

纯静态 HTML + 原生 JS + JSON 题库（按章节懒加载），localStorage 存做题记录/错题/进度，无后端无构建。

## 题库来源

用户百度网盘分享（696 文件 / 28 目录 / 610MB）。采用「题目+解析」版 PDF 入库：
- 公共科目：章节练习（基本知识+岗位能力全章节）+ 预测模拟 6 套 + 历年真题 11 套（2013–2024）
- 数学1：章节练习（高数/线代/概率）+ 预测模拟 16 套 + 历年真题 2018–2024
下载方式：BDUSS Cookie + pcs API（`method=download`），分享虚拟路径 `/sharelink385058470-.../` → 真实路径 `/我的资源/`。
